# Research

Independent research reports produced by four parallel Opus sub-agents on 2026-09-16, before any product decisions were made. They are inputs to `PRODUCT_REQUIREMENTS.md` and the early ADRs, not decisions themselves. Where a report and an ADR disagree, the ADR wins.

| # | Report | Question it answers |
|---|--------|---------------------|
| 01 | [Landscape and competitors](01-landscape-and-competitors.md) | Who is Catalyst, what do forecasting/causal tools get right and wrong, what would be distinctive vs. cliché |
| 02 | [Causal modeling formalisms](02-causal-modeling-formalisms.md) | Which formalism supports "modify a node, re-propagate" honestly; LLM forecasting literature; proposed data model |
| 03 | [UI/UX directions](03-ui-ux-directions.md) | Canvas tech, multiverse/diff visualization, three design directions, anti-patterns, accessibility |
| 04 | [Engineering structure](04-engineering-structure.md) | Stack, repo skeleton, Docker, testing layers, ADR/spec format, git hygiene, data sources |

Each report carries its own URLs. Claims flagged as unverified in a report remain unverified here.
